I’ve integrated **Nutrient Document Web Services (DWS)** directly into a Microsoft Word Add-in, bringing **cloud-scale document processing and AI** right into the desktop experience you already use every day.

The Office Add-in requires certain prerequisites, including web hosting (Azure Web App), Azure AD (with M365 integration), Power Automate and DWS API. These apply if the customer wants to self-host. If we host it instead, we can create a multi-tenant app and then publish it to AppSource.
