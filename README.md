# 📄 Nutrient Viewer Word Add-in (POC)

## 👋 Overview  
This is a simple proof of concept showing how **Nutrient Web SDK (via DWS)** can be integrated directly into **Microsoft Word** to automate document processing — like **PII redaction — in seconds**.

👉 Stay in Word → Click → Get a redacted PDF instantly.

## ⚙️ How It Works  

1. Open your document in Word  
2. Click the **Nutrient Viewer Add-in**  
3. Send document to **Power Automate**  
4. Flow calls **Nutrient APIs (DWS/Web SDK)**  
5. Receive a **redacted PDF** in seconds  

---

## 🚀 Tech Stack  

- Microsoft Word Add-in (Office JS)  
- Power Automate  
- Nutrient Web SDK (DWS)  
- Azure (Hosting + Authentication)  

---

## 🧱 Prerequisites (Self-Hosted)  

- Azure Web App  
- Azure AD (Microsoft 365 integration)  
- Power Automate  
- Nutrient API / DWS access  

---

## ☁️ Hosted Option  

We can host this as a **multi-tenant app** and publish it to **Microsoft AppSource**, removing the need for setup.
